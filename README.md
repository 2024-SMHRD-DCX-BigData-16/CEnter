# CEnter
openAI api를 활용한 코딩 학습 도우미

서비스 소개
서비스명 : CEnter(AI융합 코딩 학습 가이드)
서비스 설명 :
1. AI기반 맞춤형 코딩 문제를 추천 받고자 함
2. AI가 추천해준 예제를 풀이하고, 오답을 체크할 수 있음.
3. 예제에 대한 풀이 또한 AI가 설명해주고 예제를 풀이할 수 있음.
