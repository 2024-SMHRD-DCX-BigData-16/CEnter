3. 예제에 대한 풀이 또한 AI가 설명해주고 예제를 풀이할 수 있음.

기대효과
1️⃣ AI 기반 맞춤형 코딩 학습 제공
✅ 개별 학습자의 실력과 관심사에 맞는 문제를 자동 추천

2️⃣ 학습 효율성 극대화
✅ 반복적인 문제 풀이보다 단계별 맞춤 문제 제공으로 학습 속도 향상


3️⃣ 기존 학습 플랫폼과 차별화
✅ 단순 문제 풀이가 아닌 AI 기반 개별 맞춤형 학습 시스템 제공
✅ ChatGPT API와 연동하여 자동 문제 생성 및 해설 제공


4️⃣ 자기주도 학습 환경 조성
✅ 학습 이력을 저장하여 지속적인 복습 및 개선 가능

향후 발전방향
🔹 1. AI 학습 코치 기능 도입
✅ AI가 학습자의 코드 스타일과 오류 패턴을 분석하여 맞춤 피드백 제공

🔹 2. 다양한 언어 및 프레임워크 지원
✅ Python, Java, C뿐만 아니라 JavaScript, React, Spring, Django 등 다양한 기술 스택 지원

🔹 3. AI 기반 실시간 코드 분석 및 자동 디버깅
✅ 추천 코드 개선 기능 추가 (성능 최적화, 코드 가독성 향상 등)

🔹 4. 커뮤니티 및 협업 기능 추가
✅ 팀 프로젝트 기반 학습 기능 도입하여 협업 학습 환경 조성

🔹 5. AI 기반 채점 및 코드 평가 시스템
✅ 기업이 원하는 기술 스택에 맞춰 맞춤형 코딩 테스트 자동 생성
 



결론 
1. AI 기반 코딩 학습 서비스의 혁신적인 발전 가능성
2. 자기 주도적  학습 환경 조성
3. 글로벌 IT 시장의 무한한 성장 가능성을 활용한 경쟁력 확보

   팀장 : 이현건(PM, BACK-END)
   팀원 : 박명훈(BACK-END, DB구현)
   팀원 : 강래우(FRONT-END, CRAWLING)
   팀원 : 차황현(FRONT-END, BACK-END)
